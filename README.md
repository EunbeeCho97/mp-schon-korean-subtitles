
# German Modal Particle *schon* in Korean Subtitles

## About this repository

This repository contains Python scripts associated with the study:

**Teaching the Untranslatable: What Korean Subtitles Reveal About the German Modal Particle Schon**

Published in *Die Unterrichtspraxis / Teaching German*.

The study investigates how the discourse-pragmatic functions of the German modal particle *schon* are represented in Korean subtitles.

## Research overview

The study examines 10,000 German–Korean subtitle pairs from the OpenSubtitles corpus.

Two analytical dimensions are considered:

1. Illocutionary type: assertive, directive, and interrogative.
2. Translation strategy: six categories (A–F), ranging from direct lexical correspondence to pragmatic omission.

## Code

The repository will contain:

- `01_illocution_classification.py`: Rule-based classification of German sentences by illocutionary type.
- `02_translation_strategies.py`: Rule-based annotation of Korean subtitle translation strategies.
- `requirements.txt`: Python dependencies.
- `examples/`: Illustrative input data, where redistribution is permitted.

## Reproducibility status

The scripts are being organized and checked for reproducibility. They should not yet be treated as a fully validated reproduction package.

The original subtitle corpus is not included in this repository. Data access and redistribution are subject to the terms of the original source.
